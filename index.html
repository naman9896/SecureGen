SecureGen — Secure Password & API Key Generator

SecureGen is a free, privacy-first tool that generates cryptographically strong passwords and API keys entirely in your browser using the Web Crypto API. There is no backend: nothing you create is ever sent to a server, stored, or logged.

Password generator

Adjustable length from 8 to 128 characters, toggles for uppercase, lowercase, numbers and symbols, an option to exclude ambiguous characters, and a real-time strength meter with entropy in bits.

API key generator

Output as alphanumeric, hexadecimal or Base64, add a custom prefix such as sk-, generate up to 100 keys at once, and export as TXT or CSV or view any key as a QR code.
